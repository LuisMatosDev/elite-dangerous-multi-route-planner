## English

### Features

- 📡 **Real-time journal monitoring** — reads Elite Dangerous log files automatically
- 🗺️ **Multi-waypoint route planning** — add, remove and reorder destinations
- 📏 **Distance and jump calculation** — estimated jumps and travel time based on your ship's jump range
- 🔍 **Visited systems search** — search through systems you have actually visited
- ♿ **WCAG 2.1 AA compliant** — accessible and keyboard navigable

### Requirements

- Windows 10 or later
- Elite Dangerous installed and launched at least once
- Node.js v18+ (for development)

### Installation (Development)
```bash
git clone https://github.com/LuisMatosDev/elite-dangerous-multi-route-planner.git
cd elite-dangerous-multi-route-planner
npm install
npm run dev
```

### Journal Path

The app automatically detects your Elite Dangerous journal files at:
```
C:\Users\[Username]\Saved Games\Frontier Developments\Elite Dangerous
```

## Português

### Funcionalidades

- 📡 **Monitorização de journal em tempo real** — lê os ficheiros de log do Elite Dangerous automaticamente
- 🗺️ **Planeamento de rotas multi-waypoint** — adiciona, remove e reordena destinos
- 📏 **Cálculo de distâncias e jumps** — jumps estimados e tempo de viagem com base no jump range da tua nave
- 🔍 **Pesquisa de sistemas visitados** — pesquisa entre os sistemas que visitaste
- ♿ **Conformidade WCAG 2.1 AA** — acessível e navegável por teclado

### Requisitos

- Windows 10 ou superior
- Elite Dangerous instalado e iniciado pelo menos uma vez
- Node.js v18+ (para desenvolvimento)

### Instalação (Desenvolvimento)
```bash
git clone https://github.com/LuisMatosDev/elite-dangerous-multi-route-planner.git
cd elite-dangerous-multi-route-planner
npm install
npm run dev
```

### Localização dos Journals

A app deteta automaticamente os ficheiros de journal do Elite Dangerous em:
```
C:\Users\[NomeUtilizador]\Saved Games\Frontier Developments\Elite Dangerous
```
